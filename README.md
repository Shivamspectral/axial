# ASTRA SCOE Feedback Intelligence — A4 PDF Package

This package contains the comprehensive Siddhant College of Engineering feedback system with an updated **A4 landscape** PDF report generator.

## PDF changes
- A4 landscape output.
- Uses the exact college letterhead/header supplied in `Letter-headnomination.docx` via `assets/header_logo.png`.
- Student response tables are compact and page-broken so data does not run outside the page.
- All ten question scores remain visible in the response matrix.
- Includes per-student Total, Avg /5 and percentage.
- Includes faculty average, question-wise averages, rating distribution, heatmap, division analysis, comments and methodology.
- Footer/signature areas are kept inside the A4 printable area.

No Supabase schema or backend changes are included in this update.
